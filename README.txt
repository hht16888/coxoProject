# 电机转1圈3个编码
  减速输出最高80rpm，编码脉冲80*250*3=60000(60r/ms)
  
# ADC+DMA 两路ADC 电池电压 电机电流 完成一次
  55.5周期+55.5周期 = 12.0 us 
  71.5  + 71.5      = 14.0 us
  239.5 + 239.5     = 42.0 us 
  
药物剂量： 1.7mL 长度49mm 螺距0.7mm  
           假设1分钟打完2mL，则1.7mL需要54s，长度49mm 螺距0.7mm  减速电机54s走49/0.7=70圈(77rpm)，单电机77*250= 19500rpm
		   则 2mL/min 对应 77rpm 
           Motor.Distance 一圈 = 6个码  250圈 = 1500码 = 1转 = 0.7mm  
		   Motor.Distance/6/250*0.7 = X mm
		   6码 = 1电机圈
